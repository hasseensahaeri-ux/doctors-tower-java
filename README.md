# 🏥 Medical Tower Management System

### Medical Tower \| نظام إدارة برج طبي

Medical Tower is a desktop application developed using Java and Java
Swing. It aims to simplify and organize essential management operations
in a medical tower through a user-friendly graphical interface.

## 🎯 Project Overview

The system provides a centralized platform for managing doctors,
patients, and medical appointments. It helps organize medical
information, improve appointment scheduling, prevent booking conflicts,
and reduce manual administrative work.

## ✨ Features

-   **Doctor Management:** Display and manage doctors' information.
-   **Specialties Management:** Organize doctors according to their
    medical specialties.
-   **Floor Organization:** Display the floor assigned to each doctor.
-   **Patient Management:** Record patient information when booking
    appointments.
-   **Appointment Booking:** Schedule medical appointments for patients.
-   **Appointment Scheduling:** Organize appointments using 30-minute
    time slots.
-   **Conflict Prevention:** Prevent overlapping appointments for the
    same doctor.
-   **User-Friendly Interface:** Provide a simple and organized
    graphical user interface.
